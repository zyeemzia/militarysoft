# ZyeemZia Military Software

Portfolio site for the military software built by Zyeem Bin Zia: the unit systems (Signal Simulator, STMS, SRIMS, RTMS) and the BD MIL field app suite.

**Live:** https://militarysoft.zyeemzia.com/

Static site, no build step: `index.html`, `style.css`, `app.js`, content in `data-apps.js` and `data-systems.js`, screenshots in `img/`.
Unit-system screenshots use demonstration data; live figures, names and paths are blurred.
